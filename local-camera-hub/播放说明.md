# 云蚁摄像头接入

本机直播地址 http://127.0.0.1:18767/live.m3u8，已配置到 EasyNVR。2026-11-07 排查时该摄像头仍离线，当前连通性以 [中继状态](http://127.0.0.1:18767/status) 的状态和帧计数为准。

总入口由 relay_manager.py 按 EasyNVR 设备清单启动适配器。单独维护时可使用本目录 start-live.ps1 与 stop-live.ps1，避免与管理器持有的实例同时连接。

桥接使用 python32/python.exe、兼容的官方 32 位 SDK 和 FFmpeg。serve_live.py 管理中继，verify_p2p.py 读取本人设备的 P2P H.264 视频并输出 HLS。camera-private.json 包含设备访问参数，仅用于本人设备；官方客户端登录不会自动更新这些参数。

连接失败时，先用官方客户端确认设备网络和画面，关闭其他非必要预览，再核对 SDK 位数、连接参数和状态。WinError 193 常见于运行时与 DLL 位数不一致。P2P -3006 需要结合网络、参数和设备并发限制排查。

2026-11-05 历史实测 HLS 高清为 1280×720，标清为 640×360，当前桥接未提供音频。相关结果保存在 [验证记录](验证结果.md)、hd-result.json 和 live-playback-check.log。换机及其他通道见 [主手册](../摄像头获取与事件预览-完整部署手册.md)。
