# 旧迁移工具说明

本目录保留早期 Windows 打包脚本。旧的压缩包和解压目录已清空。当前版本的换机部署以 [监控项目部署与运维手册](../摄像头获取与事件预览-完整部署手册.md) 为准。

build_package.py 仍是早期打包清单，未覆盖当前的 ArtPlayer、YOLO26s 与 ByteTrack、智能录像、每日分析和逐文件覆盖，也未完成新电脑的端到端验证。需要一键迁移时，应先更新脚本清单、相对路径与运行环境，并在目标电脑验收。

早期部署包的入口依次是 01-Login.cmd、02-Start.cmd、03-Check.cmd 和 04-Stop.cmd。Run 01-Login first 提示表示新机未找到有效的官方天翼登录，请在新机官方客户端登录并保存。resolve-tianyi.ps1 是旧包用于定位登录文件的辅助脚本。

历史录像、事件图片和分析数据要单独备份。新机重新保存天翼登录和 DeepSeek 密钥。含设备访问配置、EasyNVR 数据库或密钥的备份只在本人设备间保管。
