# 监控系统完整部署包

适用 64 位 Windows 10 或 11。完整解压到固定目录，例如 `D:\CameraMonitor`。安装系统服务后，应在同一目录运行。

## 启动顺序

1. 运行 `01-Login.cmd`，在天翼客户端重新登录并保存登录，确认正面和侧面能播放。云蚁客户端可用于核对联网和画面。确认后关闭不必要的实时预览，避免占用云蚁 P2P 连接。
2. 右键以管理员身份运行 `02-Start.cmd`。它会把录像和前端路径指向解压目录，安装或启动该目录的 EasyNVR 服务，再启动直播中继、事件预览、目标检测和智能录像。如果已装着另一套同名 EasyNVR 或端口被其他程序占用，启动会提示冲突。
3. 打开 [EasyNVR 视频调阅](http://127.0.0.1:10000/cloud/#/preview)，使用原管理账号登录。两路天翼是按需拉流，打开画面并等待约一分钟，确认新录像写入。EasyNVR 如要求激活，使用新电脑对应的有效授权。
4. 用 `03-Check.cmd` 检查各模块。天翼看 `live=True`，云蚁看 `status=live`，逐文件覆盖看 `status=ready` 和 `limit=85.95%`。在 [事件预览](http://127.0.0.1:18768/) 检查事件与回放。
5. 打开 [每日分析](http://127.0.0.1:18768/daily)，重新输入 DeepSeek API Key。日报地点、任务限额等设置来自原项目。

首次使用前，新机器可能需要系统的 Microsoft .NET Framework 及 Visual C++ 运行库。程序使用包内 Node、FFmpeg 和 Python，无需为检测另装 pip 包。Windows 重启后重新运行 `02-Start.cmd` 启动项目子服务，必要时重新打开按需通道。

## 归档范围

- EasyNVR 程序、前端资源、设备和录像计划，以及一致性 SQLite 配置副本。
- 两种官方客户端程序、云蚁所需 SDK、32 位 Python、64 位 Python 及检测依赖、Node 和 FFmpeg。
- YOLO26s ONNX、训练权重和 YOLOX 回退权重，以及当前代码、开关、通道接入设置和文档。
- 85.95% 按最旧完成片段逐文件覆盖。原厂兜底配置为 95.95%，录像保留期限仍为 5 天。

历史录像、事件图片、日报数据、运行缓存和旧机器的天翼登录文件已排除。天翼播放列表是无签名的本机占位地址，由新登录续签后替换。云蚁设备参数如失效，需要重新获取；备份时云蚁仍离线。原机 DeepSeek 密钥与 Windows 账户绑定，归档保留其他日报设置。

本包含设备私有参数和 EasyNVR 账号配置，应按私有备份保管。包内 `manifest-sha256.json` 提供逐文件校验，压缩包旁另有整体校验文件。新电脑上的厂商登录、EasyNVR 激活和实际拉流需在目标环境验收。
